# Manual Testing 

## Overview

This repository demonstrates a manual testing exercise performed using **Jira** for test case management and test execution.

The testing focused on validating the login functionality of a web application using different email and password combinations.

## Testing Tool

* **Jira** – Test case management and execution
* **Testing Type:** Manual Testing
* **Test Area:** Login Functionality

## Test Cases

| Test Case | Test Scenario                      | Expected Result                      |
| --------- | ---------------------------------- | ------------------------------------ |
| TC-01     | Valid email and valid password     | Login should be successful           |
| TC-02     | Invalid email and Valid password   | An error message should be displayed |
| TC-03     | Valid email and wrong password     | An error message should be displayed |

## Test Execution Summary

* **Total Test Cases:** 3
* **Passed:** 3
* **Failed:** 0
* **Blocked:** 0
* **Defects:** 0

All three test cases were manually executed and passed successfully. The Jira execution report is included in this repository as evidence of the test execution.
